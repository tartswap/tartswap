# Security Policy

TartSwap is a decentralized exchange and DeFi ecosystem on BNB Smart Chain
(BSC). We take the security of our smart contracts and web application
seriously, and we appreciate the efforts of security researchers who help keep
the project and its users safe.

## Reporting a Vulnerability

If you discover a security vulnerability, please report it privately so we can
address it before it is publicly disclosed.

- **Email:** info@tartswap.com

If you do not receive a timely response, you can also reach the maintainers
through the project's official channels linked from https://tartswap.com.

Please include as much detail as you reasonably can:

- A description of the vulnerability and its potential impact
- Steps to reproduce, or a proof of concept
- Affected contract address(es), URL(s), or component(s)
- Any suggested remediation, if you have one

**Please do NOT open a public GitHub issue, pull request, or social-media post
for security matters.** Public disclosure before a fix is in place puts user
funds at risk.

## Scope

This policy covers:

- The TartSwap smart contracts deployed on BNB Smart Chain (BSC)
- The TartSwap web application and its supporting APIs

Out of scope: third-party services and dependencies (wallets, RPC providers,
infrastructure vendors), and issues that require physical access, social
engineering, or a compromised user device.

## Disclosure & Recognition

Please give us a reasonable amount of time to investigate and remediate an
issue before any public disclosure. We will acknowledge valid reports and keep
you updated on our progress.

There is no formal paid bug-bounty program at this time. That said, good-faith
reports are genuinely appreciated, and we are happy to publicly credit
researchers who responsibly disclose valid issues (unless you prefer to remain
anonymous).

Thank you for helping keep TartSwap and its users safe.
